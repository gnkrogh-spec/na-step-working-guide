# NA App Prototype 3

Mobile-first prototype of the Interactive Working Guide to the 12 Steps of NA.

## New in Prototype 3
- Backup & Restore across all 12 Steps
- Export My Answers creates a JSON backup containing answers, notes, and resume state
- Restore My Answers imports a previously created backup
- Automatic local saving remains enabled
- Prototype 2 mobile navigation retained

This is a testing prototype, not the final iPhone/Android app.

- Share My Answers is available directly from each Step Summary.
